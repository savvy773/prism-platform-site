# PRISM 소개 페이지

PRISM 프로젝트의 공개 소개 페이지입니다. 원본 프로젝트 저장소와 업무 데이터는 공개하지 않습니다.

- 주소: https://savvy773.github.io/prism-platform-site/
- 구성: 정적 HTML·CSS, GitHub Pages, 대본 기반 영상 팩토리(`apps/video/`)
- 게시: `main` 브랜치의 루트 디렉터리

`assets/`의 WEB·ERP 이미지와 영상 속 화면은 실제 캡처가 아닌 구성 예시입니다.

영상은 `apps/video/projects/<영상 ID>/script.ts` 대본 하나로 만들고, `just video make <영상 ID>`로 음성·영상·자막을 생성합니다. 자세한 절차는 [영상 작업 설명서](docs/VIDEO_WORKFLOW.md), 집·회사 간 작업은 [Git 동기화](docs/GIT_SYNC.md)를 참고하세요.
