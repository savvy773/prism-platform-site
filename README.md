# PRISM 소개 페이지

PRISM 프로젝트의 공개 소개 페이지입니다. 원본 프로젝트 저장소와 업무 데이터는 공개하지 않습니다.

- 주소: https://savvy773.github.io/prism-platform-site/
- 구성: 정적 HTML·CSS, GitHub Pages, 독립 Remotion 영상 앱(`apps/video/`)
- 게시: `main` 브랜치의 루트 디렉터리

소개 내용은 공개해도 되는 프로젝트 개요만 담습니다. `assets/`의 WEB·ERP 이미지는 실제 화면 캡처가 아닌 구성 예시입니다.

영상 미리보기는 `just video`, MP4 추출은 `just video render`입니다. 영상별 대본과 출력은 `apps/video/projects/<video-id>/`에서 관리합니다. 자세한 절차는 [영상 작업 설명서](docs/VIDEO_WORKFLOW.md)를 참고하세요.
